# Multi-Channel Telegram Premium Emoji Post Bot

## Railway Variables

### BOT_TOKEN
توکن ربات از BotFather.

### CHANNELS
چند کانال را با این فرمت وارد کن:

فروش=-1001234567890,VIP=-1009876543210,تست=-1005555555555

نام کانال می‌تواند فارسی باشد. بین کانال‌ها کاما بگذار.

## روند کار

1. کاربر `/start` می‌زند.
2. «📤 ارسال پست» را می‌زند.
3. ربات دکمه کانال‌ها را نمایش می‌دهد.
4. کاربر کانال را انتخاب می‌کند.
5. متن پست را می‌فرستد.
6. `[emoji_id]` به Telegram custom emoji تبدیل می‌شود.
7. پست به کانال انتخاب‌شده ارسال می‌شود.

## نکته
ربات باید در هر کانالی که در CHANNELS قرار می‌دهی Admin باشد و اجازه Post Messages داشته باشد.

خود اکانتت لازم نیست Premium باشد.
